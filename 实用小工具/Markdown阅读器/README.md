# Markdown 阅读器

双击 [index.html](index.html)，在浏览器中阅读 Markdown。操作手册和其他项目文档均通过选择原文件加入，在同一文档列表中切换；不再内置手册快照。无需安装应用、登录账号或启动服务。

## 开始使用

1. 双击 `index.html`。首次打开显示“暂无文档”和“打开文档”按钮；已有记住的文件时恢复列表。载入后左侧是文档列表、中间是正文、右侧是分级目录；窄屏改为顶部的文档与目录按钮。如果页面空白，确认 `reader.js`、`reader.css` 和 `vendor/` 随入口一起保留，并记录浏览器和错误画面。
2. 点击“打开文档”，选择操作手册或其他文档的原始 `.md`。预期左侧新增或选中条目，状态明确显示“原文件”或“本次载入”。旧版内置快照不再显示，已有的原文件授权记录继续使用。
3. 继续点击“打开文档”，从其他目录添加 Markdown。预期每份文档可独立切换，目录随正文改变。可用左侧搜索框筛选文件；同名文件以序号区分，移除条目不会删除原文件。

左侧文档条目可直接用鼠标拖动上下排序；已记住的原文件会保存这个顺序。拖动只改变阅读器列表，不会移动或重命名磁盘文件。

工具栏只保留一个“打开文档”入口：优先请求可重读的原文件访问权限；浏览器不支持或无法提供该权限时，自动使用普通文件选择，状态显示“本次载入”。取消选择不会导入文件或再弹出另一种选择框。

所有文档条目都有叉号，点击只移除列表记录和已保存的文件引用，不删除或修改磁盘文件。移除当前文档后选中剩余的第一份文档；移除最后一份后显示“暂无文档”，清空正文和目录。已移除条目不会在重开时恢复，之后可通过“打开文档”重新添加。

选择范围仅为主动选中的文件，不扫描电脑或其他项目。支持 `.md`、`.markdown`、`.txt`；每份文件不超过 8 MB，使用 UTF-8 编码。错误格式、编码或大小会提示，其他已载入文档仍可阅读。

## 阅读、定位与复制

- 右侧目录支持章节搜索、点击跳转、当前位置高亮和长目录跟随。切换文档后恢复该文档的阅读位置。已记住的原文件还会保存滚动位置；这是数字位置，正文大幅调整后可能需要重新定位。
- 顶部放大镜打开正文搜索，可前后切换结果。搜索当前文档，包括代码块，最多标记 1000 个结果；不跨不同格式文本节点匹配，不保存搜索词。关闭搜索即清除高亮。
- 提示词代码框右上角的复制图标只复制框内原文，保留缩进和换行，CRLF 统一为 LF。代码框外的说明不在复制范围内。浏览器拒绝剪贴板时，会打开已全选的只读文本框；使用系统复制即可。
- 顶部主题按钮切换浅色、深色，并在浏览器允许时记住偏好。可使用浏览器打印；工具栏和侧栏不进入打印正文。
- 普通标题锚点和单独一行的空 `<a id="..."></a>` / `<a name="..."></a>` 支持跳转。相对文件链接只列出已载入的同名候选，由用户确认对应文档后跳转。文件选择接口不提供完整路径，不能仅凭文件名推断项目关系；未载入的目标需要主动选择。

## Markdown 更新后怎样同步

**已选择的 Markdown 在读取时直接解析，日常更新原文不需要生成 HTML。**

先在原编辑器中保存 MD。通常无需关闭或重开阅读器：下文“刷新”指页面右上角的圆形箭头按钮，悬停提示为“重新读取当前文件”，不是浏览器重新加载或 F5。浏览器重新加载会重建页面；“本次载入”的文档不会保留，需要重新选择。

| 页面状态 | 同步方式 | 重开后的表现 |
| --- | --- | --- |
| 原文件 · 已记住 | 切换到该文档、返回阅读器窗口或标签页、点击刷新时尝试重读；需要有效读取权限 | 恢复已记住的文件列表和上次成功读取的正文；尝试重读上次选中的文档，找不到则选第一份；其他条目在选中时读取 |
| 原文件 · 本次授权 | 当前页面仍可重读原文 | 需要重新选择 |
| 本次载入 | 点击刷新并重新选择同名原文件，更新当前条目；请核对目录，工具不能确认同名文件是否来自同一位置 | 需要重新选择文件 |

自动记忆依赖浏览器文件系统访问接口。保存的文件句柄是浏览器用于访问原文件的引用，不保证授权永久有效。为避免重开后因权限暂时失效而出现空白页，阅读器会在浏览器本地数据库保存每份原文件上次成功读取的正文；它不会上传、修改或删除原文件。权限不足时，页面仍显示“重新授权 / 重试”，但有缓存时会继续显示上次内容，并明确提示该内容可能不是最新版本。文件移动后的引用是否仍有效取决于浏览器和文件系统；原文件无法读取且没有缓存时才显示空正文。

选中左侧的“原文件”条目后，点击刷新即可通过这个引用重读磁盘上的最新内容，无需重新输入路径。普通选择只提供本次文件副本，不提供可复用的路径权限，因此仍需重新选择同名原文件；不能仅凭左侧文件名自动定位磁盘文件。没有文档或切换文档尚未完成读取时，刷新按钮禁用。

这不是后台文件监听。阅读器一直在前台时，保存原文件后点击刷新即可。工具关闭时不会工作；不扫描目录，也不自动发现新文件。添加新文档仍需主动选择。

预期结果：保存的新正文会出现，新增标题也会加入目录。原文件成功重读但内容未变时，读取时间仍会更新；手动点击刷新会提示“已重新读取，内容没有变化”，自动重读则不弹提示。结果不符时，先确认 MD 已保存、当前选中原文件条目及正确目录，再记录载入状态、浏览器和错误文字。当前文件读取失败不妨碍切换到其他文档。

浏览器、用户配置和入口地址隔离存储；更换浏览器、移动阅读器、清除浏览数据后可能需要重新选择，已缓存的正文也会随浏览器数据清理而消失。Windows/macOS 可用现代浏览器阅读，但自动记忆取决于浏览器及授权。Safari/Firefox 等不支持相关接口时使用普通选择模式，不能承诺与 Chromium 浏览器完全一致。

## 内容与安全边界

支持标题、段落、列表、表格、链接、围栏代码块。使用 Markdown 解析库，不执行正文中的代码、命令或提示词。除上述严格限定的空锚点外，原始 HTML 显示为文本。公式、Mermaid、附件图片渲染暂不支持；图片显示替代文字，不自动读取本地资源或加载外部图片。外部网页只在用户点击链接时打开。

界面资源全部随工具分发，不用 CDN、不上传文档、不接入 AI 或第三方分析。浏览器保存文件引用、文件名、阅读位置、主题，以及已记住原文件上次成功读取的正文；不保存搜索词。浏览器扩展、系统同步和宿主隐私设置不属于工具的控制范围。

只读阅读授权不等于公开或发送文档的授权。不要将自己的私密文档写进分发包；文档应通过运行时选择打开。

## 验证

已在 Windows 无头 Chrome 和 Edge 验证：载入整本手册后，43 个标题、40 个围栏代码块与源文一致；2F/2G 及子标题跳转；多文件切换、阅读位置恢复、重复标题、旧锚点、跨文件候选确认、正文搜索和搜索后复制；普通模式重新选择不新增条目；首次空列表、所有条目可移除、移除最后一份后清空、重开不恢复已移除条目、移除记录不修改源文件；错误编码；脚本不执行及图片不外联；1440 像素桌面、390 像素窄屏和明暗主题。测试未发现页面异常或外部网络请求。

复制成功路径使用测试接收器核对文本；拒绝路径核对只读文本框包含完整原文。句柄保存、重开、更新、删除和权限状态使用本机 HTTP 测试页与浏览器私有测试文件或替身验证，不等于操作系统文件选择器验收。

**仍待人工确认：** `file:` 双击入口的真实授权记忆、系统剪贴板、macOS/Safari/Firefox。请选择一份可修改的测试 Markdown，在编辑器保存新标题后返回阅读器，确认状态和内容；关闭并重开确认正文可恢复，若权限失效则确认缓存内容和“重新授权”提示同时出现。复制一段到本地编辑器，核对内容完整。异常时提供操作系统、浏览器、载入模式、错误文字和目标标题。

## 维护与检查

普通使用者无需 Node.js。维护者在本目录运行：

```sh
npm ci
npm run build
npm run check
```

构建脚本从自身位置复制固定版本的解析器、图标和许可证到 `vendor/`，不再读取或打包操作手册。所有文档都在用户选择后读取；日常修改 MD 无需构建阅读器。

`npm run check` 验证 JavaScript 语法、没有遗留快照文件、双语说明哈希与互链、资源存在，并对脚本列出的本工具文本检查常见机器绑定路径；它不是完整的仓库路径或翻译质量审查。README 中文为源，修改时须同时翻译英文，构建只刷新哈希标记，不自动翻译。

已有 Playwright 和 Chrome 的环境可运行：

```sh
node browser-check.cjs /path/to/playwright
node browser-check.cjs /path/to/playwright msedge
```

或在能直接解析 `playwright` 包时运行 `npm run test:browser`。浏览器检查默认无头；仅为测试临时启动回环地址服务，结束即关闭。截图写入仓库已忽略的 `.playwright-cli/`，不作为运行依赖。缺少 Playwright/Chrome 时会报依赖或启动错误，不表示测试通过。

依赖版本由 `package-lock.json` 锁定，许可证在 `vendor/`。分发需保留阅读器入口、`reader.js`、`reader.css` 和 `vendor/`；`node_modules/` 不必分发。没有远端发布、全局安装或后台服务步骤。
