# 纯浏览器分析：虚构日志可行性验证

核验日期：2026-09-05。对象：[单文件验证页](browser-analysis-lab.html)。本报告与当前 PowerShell 分析器的实际会话能力分开，不作为真实 Codex 日志兼容声明。

## 结论与推荐

用户主动选择文件后，在浏览器内分块读取、后台解析、取消和核验缓存的路径已经在 Windows Edge 无头环境中跑通。本阶段无需引入本地程序或分别开发 Windows/macOS 界面；先验证真实解析契约与目标浏览器，再决定产品实现。

这不意味着任务面板已经可以按收藏 ID 自动定位磁盘日志。普通文件选择取得的是浏览器文件对象，页面无法据此获得通用的后台目录扫描、持续监听或重启后静默访问权限。磁盘文件改变后须重新选择，才能核验新输入；“重新分析所选快照”不能保证代表磁盘最新内容。若产品要求完全自动定位、持续刷新或复用现有 PowerShell，应另评本地读取程序的必要性与发布成本。

## 实测范围

使用现有 Playwright 与 Windows Edge 149.0.4022.62，以无头方式从本地 HTML 文件运行；没有安装系统依赖，没有读取真实会话，没有网络请求。输入均为自行生成的虚构 UTF-8 JSONL。

| 验证项 | 实测结果 |
|---|---|
| 下载小型样例，再经文件选择输入 | 3 条数据记录、2 个回合、输入 300 / 输出 50，与预设值一致 |
| 同一内容再次处理 | 完整内容校验后复用成功摘要 |
| 同文件名、字节数与修改时间，内容改变 | 指纹不同，重新解析，数值更新；未误用旧结果 |
| 文件追加记录 | 指纹与回合统计更新 |
| BOM、CRLF、完整末行无换行 | 正确解析 |
| UTF-8 多字节字符跨分块边界 | 正确解析，没有拆坏字符 |
| 错误标记、损坏 JSON、重复回合、未知类型、非法数值、超长行、空文件、非法 UTF-8 | 拒绝生成结果，不缓存部分统计 |
| 取消处理中任务 | 终止后台线程，不发布部分结果 |
| 后台线程能力不可用 | 显示明确错误，不降级为猜测结果 |
| 390px 窄屏 | 无横向溢出 |
| 页面异常与 HTTP 请求 | 本轮观察均为 0 |

大文件样例为 **67,107,270 字节，约 64 MiB**，含 16,658 条数据记录，其中 2 个完成回合，其余是每条含 4,000 个 ASCII 填充字符的虚构记录。统计结果为输入 300、输出 50，与生成时的独立预设值一致。

单次本机测量：页面报告首次校验与解析 **0.531 秒**，重复内容校验并复用缓存 **0.253 秒**。50ms 主线程计时探针在大文件测试期间执行 11 次，最大间隔约 51ms；这说明该次测试没有观察到长时间界面阻塞，不是所有机器的帧率或响应保证。未测量浏览器与后台线程的峰值内存。该样例不代表真实超长单行、图片 Base64、数十万回合或多分段会话负载。

## 实现与缓存边界

1. 单文件 HTML 内嵌 Worker 源码，通过 Blob 启动后台线程；不需要服务器、扩展、远端脚本或字体。页面内容安全策略禁止网络连接，仅允许本地 Blob Worker。
2. 只支持显式 `synthetic-session-lab / schema 1 / synthetic: true` 的自定义格式。标记能排除普通真实日志，但不证明任何被人为标记的外部文件已脱敏；仅应使用自行生成的虚构样例。
3. 每块 256 KiB。先校验全部内容，再解析；解析时重新校验同一内容指纹，两次不一致则拒绝保存。使用流式 UTF-8 解码，保留有限的跨块行尾与回合去重表，不一次读取整个大文件。
4. 内容指纹由解析器版本、分块算法版本、块大小、文件字节数与有序块 SHA-256 组成，再做 SHA-256。它不是普通文件 SHA-256，不用于安全认证。不能只依赖名称、大小或修改时间；缓存命中仍需完整读取一次，不能承诺零读取或瞬时刷新。
5. 缓存只保存最多五个成功摘要，留在页面内存；刷新或关闭页面即清除，不保存正文或文件访问权限。失败、取消均不写入缓存。
6. 单文件上限 256 MiB，单行上限 1,048,576 个字符，唯一回合上限 100,000。这是本验证页的保护范围，不是浏览器能力上限。内存仍受最长行、回合表、浏览器实现和垃圾回收影响。

## Windows/macOS 兼容判断

| 层次 | 判断 |
|---|---|
| 同一 HTML 界面 | 可保留共同实现方向，无须因系统不同先拆成两套 |
| 主动文件选择、Blob 与后台线程 | 标准浏览器能力支持该设计；仍需检查具体浏览器版本与本地文件策略 |
| Windows Edge | 已实测上述交互与解析 |
| macOS Safari、macOS Chrome、Firefox | 未实测；当前环境没有对应浏览器运行条件，不将文档支持或模拟设备等同实机通过 |
| 保存目录权限、自动发现新分段 | 本页不实现；目录选择接口可用性更窄，不能作为无差别跨浏览器前提 |
| 重启后任务收藏与结果 | 原任务面板的本地存储只是界面便利；不代表日志仍可读取或结果仍然有效 |

已核对的浏览器来源：[File 与用户选择](https://developer.mozilla.org/en-US/docs/Web/API/File)、[Blob 分块读取所用的 arrayBuffer](https://developer.mozilla.org/en-US/docs/Web/API/Blob/arrayBuffer)、[Web Workers](https://developer.mozilla.org/en-US/docs/Web/API/Web_Workers_API/Using_web_workers)、[Web Crypto digest](https://developer.mozilla.org/en-US/docs/Web/API/SubtleCrypto/digest)、[目录选择的兼容限制](https://developer.mozilla.org/en-US/docs/Web/API/Window/showDirectoryPicker)。Web Crypto 的单次 digest 不支持流式输入，因此本页对固定小块分别计算摘要，不对整个大文件一次性分配数组。

## 接入真实分析前的必要工作

1. 确定最低浏览器版本与文件选择方式，用 macOS 实机验证离线 Worker、编码与文件权限；不依赖用户代理字符串伪装完成验收。
2. 将现有分析规则转为可核对的数据契约，先用虚构的真实格式兼容样例比较新旧解析器，覆盖回合、Token 基线、多分段身份和重叠检查；本页简化统计不能直接替换原分析器。
3. 验证持续写入、截断、轮转、重命名、分段新增/丢失、超长记录和中止恢复，明确何时必须重新选择文件。真实数据测试需要独立范围授权。
4. 先决定摘要与详细报告包含哪些内容，再实现存储、清除和导出。页面内统计无需将正文上传或交给网络服务；文件选择不自动授权上传。

只有上述验证表明纯浏览器无法达到必要的自动定位、刷新或性能要求，才引入最小本地读取层；不因“桌面程序看起来完整”提前增加安装、签名与多平台发布成本。
