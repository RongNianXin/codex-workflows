# Windows 会话查询工作台

[English](README.en.md)

版本：`0.2.0-dev.7`。**本版本开放真实本地会话查询。** 只填任务 ID，保存后点击查询，右侧显示原分析器的统计与报告。源会话只读，不上传数据，不安装依赖。

## 使用方法

1. 完整解压到较短路径，双击根目录 `Start-SessionDesk.cmd`；从仓库运行时双击本目录同名文件。不要单独打开 HTML。Windows PowerShell 5.1 启动后台服务并打开默认浏览器；本轮测试 Windows Edge。
2. 填写任务 ID（必填）并保存。名称和项目不再手填；清单没有固定条数上限，回归验证 20 条，海量清单性能未验证。相同 ID 重复新增会拒绝，不覆盖旧记录。
3. 点击该行“查询/刷新”，查看右侧文本和“查看详细报告”。只分析该 ID 匹配且通过会话身份核对的本地日志；包含活动及归档目录，不会查询云端任务。找不到本地日志时明确失败。
4. 可按项目、名称或 ID 搜索，查看已有结果或删除清单项。列表第一行项目左对齐、名称右对齐，下一行显示 ID。
5. 上方可切换简体中文和 English，提示、统计及报告同步切换；用户名称、项目、路径和日志原文不翻译。有查询运行时暂不能切换。各任务按语言保留本页结果和报告；切回已有语言直接显示原快照，缺少该语言时只重新查询当前任务，其他任务结果保留。查看另一语言的旧结果时明确提示；手动查询/刷新会清除该任务两种语言的旧结果，失败不恢复旧成功。成功结果及详细报告按任务和语言保存为本地历史快照，页面刷新、退出服务后重开可恢复；保留原查询时间，并标明不是实时状态。
6. 不再使用时点击页面顶部的“退出工具”。出现醒目的“现在可以关闭此页面”提示后关闭网页。仅关闭网页不会停止后台服务；退出不删除已保存任务或结果。

启动失败时提供错误文字，不发送真实日志，不修改全局执行策略或提权。旧版 PowerShell 对过深路径可能报找不到文件，应缩短解压位置。

## 名称与项目同步

会话名称来自本机 `session_index.jsonl` 的最后一条有效匹配记录；项目来自 `.codex-global-state.json` 中任务到本地项目的明确关联及项目名称。默认读取用户配置目录中的 `.codex`，设置了 `CODEX_HOME` 时使用该目录。不会用文件夹名、日志内容或人工标签猜测项目名。

页面可见时约每 3 秒核对一次元数据，即名称、项目这类描述信息；名称改变不触发日志重新统计。Codex 将改名保存到磁盘后，清单、右侧标题、输出文本的名称栏及已打开报告的名称栏同步更新。项目大小写变化同样更新。历史日志中出现的旧名称仍是历史原文，不全局替换。磁盘中的原分析器报告保持查询时快照；页面的名称与项目栏使用最新可用信息，统计数字仍属于原查询时间。

这些桌面记录是当前已观察到的本地格式，不是承诺长期稳定的公共接口。远端项目、无关联任务、缺失文件、损坏或截断记录以及 Codex 尚未落盘的改名，不能保证取得最新名称或项目。界面保留上次标签并明确标注信息未更新；新任务显示未取得。不能把旧标签当作当前已确认归属。不会自动写回或修改 Codex 的元数据文件。

## 数据与兼容性

每个实例的数据在本目录 `.local/`，默认实例为 `main`：

- `main/tasks.json` 保存 ID、上次名称和项目、语言设置；文件原子替换，损坏时不清空。
- 支持读取旧 schema 1、2 清单。schema 1 先精确备份到 `tasks.schema1.<随机标识>.bak`，再迁移。原有手填标签只作为历史值，检测到当前来源后更新；不再提供手填编辑入口。
- 升级前退出旧服务，把旧 `.local` 复制到新包 `windows-local/.local`，不要覆盖已有新清单。也可从独立保留的备份恢复。回退旧版前退出服务并恢复迁移前备份；后续新增数据不会自动合并进旧备份。
- `main/reports/` 保存原分析器报告与元数据，报告可能包含高消耗回合的完整用户输入和本机路径。只保存在本地，删除任务记录不会删除报告。
- `main/runtime/` 保存分析器运行副本，原分析器源码与算法不改。`main/connection.json` 是本次服务的随机凭证，退出后移除。

`.local` 是私有数据，不得随 ZIP 分发、提交或公开。清单保存在磁盘，不依赖浏览器缓存；已验证服务重启，未重启操作系统。删除程序目录会同时删除其中数据，清理前先备份。

## 执行边界

- 仅监听 `127.0.0.1`，校验 Host、Origin 和随机令牌；不允许客户端传入脚本、命令或文件路径。
- 只有已保存且格式有效的 ID 可以查询。日志按 ID 筛选并核对记录身份，Codex 源日志及元数据只读。
- 同一数据目录单写者；最多两个查询同时运行，与清单容量无关。同任务同语言重复请求复用当前运行；120 秒超时或服务退出时终止本服务启动的分析子进程。
- 查询清除旧显示，结果绑定任务及运行标识；失败时不开放旧报告。名称更新与统计更新分开，不能把页面当成 AI 实时执行状态。
- 原统计策略不变，仍以原脚本的完整性提示和已知限制为准。持续写入的会话可能在分析过程中变化，结果是读取快照，不是原子冻结的实时总账。

## 维护、打包和验证

UI 文本集中在 `desk.html` 的 `messages`，每键中文、英文成对维护。中文变化须同步审阅英文并更新 `I18N-SOURCE-SHA256`，服务错误和说明也须双语同步。指纹只能检测中文变化，不能替代语义审阅。

使用已有 Node、Playwright、Edge 运行：

```sh
node .github/scripts/Test-WindowsSessionDesk.cjs
```

回归始终只用隔离虚构数据，覆盖只填 ID、20 条保存、重复拦截、迁移备份、改名与项目同步、打开报告后继续改名、统计保持、双语、失败清旧、截断元数据、访问限制、窄屏及退出。真实模式分支也通过指定虚构 `CODEX_HOME` 验证，不接触开发者真实会话。

打包使用：

```powershell
pwsh -File .github/scripts/Build-WindowsSessionDesk.ps1
```

脚本先核对当前仓库工具目录及交付目录中旧工作台服务的入口、PID 和连接凭证，再请求正常退出。无法安全退出则停止打包，并提示在旧网页点击“退出工具”；不批量杀掉 PowerShell。只打包精确列出的 10 个程序及说明文件，排除 `.local`，已有包不覆盖。仓库以外的旧副本不自动处理，须在其页面手动退出。

自动回归使用隔离虚构数据；操作者已反馈 dev.6 人工使用通过，但这不代表所有真实日志的统计已完成独立核验。使用者可输入自己的 ID 查询并与原脚本对照；异常请反馈错误文字或脱敏摘要，不直接提供报告原文。macOS、云端或远端任务、超大日志、海量清单、操作系统重启及设备策略差异尚未验证。

## 清单排序

每个任务的 ↑ / ↓ 在完整清单中移动一位，并保存到磁盘；首项不能上移、末项不能下移。选中任务用浅蓝背景与边框标记，内容不位移。

“常用任务”旁的“一键整理查询列表”按项目首次出现顺序分组，组内原顺序不变；例如 2、4、3、1、5 整理为 2、1、4、3、5。按已核实的项目标识分组，同名但不同项目不合并；未取得项目的任务分别保留。搜索筛选不改变操作范围，整理作用于完整清单。鼠标悬停或键盘聚焦按钮显示当前语言说明，移开并失焦后消失。

本版回归补测语言往返后多任务结果与报告保留、名称值列对齐、选中无位移、箭头及重启保序、稳定分组与重复整理、无效排序请求、双语悬停说明。所有样例均为虚构数据。

## 报告展示

新增任务区只保留任务 ID 与“保存任务”，移除重复的表单清空按钮。基本报告与详细报告用分隔线和独立文本区区分；“查看详细报告”展开后变为“关闭详细报告”，再次点击即可收起。切换任务或语言、开始新查询时收起详细报告，避免误看上一项内容；收起不删除本页缓存。中英文按钮和区域标题同步切换。

## 查询历史与退出

每个任务的每种语言最多保留最近一次成功查询的基本输出和详细报告，存于 `.local/main/snapshots/`，不建立多版本历史。手动刷新清除当前显示，成功保存后才替换该语言的历史；失败或退出导致查询中断时，旧成功历史仍保留。重开时明确显示旧查询时间和历史提示，不把旧结果当成本次刷新成功。其他语言的历史保留各自时间。删除任务清除其可恢复快照，原报告与文件替换备份不自动删除。

历史绑定数据来源、运行模式与分析器指纹，来源变化或单项文件损坏时提示对应历史不可恢复，其他任务继续可用。每任务快照最多 16 MiB；过大或写入失败会显示“查询成功，但历史保存失败”，不能保证该次结果重开可用。历史可能含会话原文，只存本地，不随 ZIP 分发。

从 dev.5 升级保留清单，但不能从旧版未保存的基本输出复原完整历史。dev.6 首次成功查询后开始保存；以后升级应保留整个 `.local`。退出后重开已用虚构样例验证，未实际重启操作系统，也未读取真实会话验证。
