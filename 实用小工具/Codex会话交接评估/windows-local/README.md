# Windows 会话查询工作台

[English](README.en.md)

版本：`0.2.0-dev.2`。保存常用任务，点击查询，右侧显示原分析器的文本和详细报告。**当前仅使用隔离虚构数据，不读取真实会话。**

## 使用方法

1. 完整解压交付包，双击根目录 `Start-SessionDesk.cmd`；从仓库使用时，双击本目录的同名文件。后台服务启动后自动打开默认浏览器；本轮实测 Windows Edge。
2. 填写任务 ID（必填），归属项目和对话窗口名称均可留空。首次体验可展开“填入隔离验证 ID”，填入示例一并保存。
3. 点击该任务的“查询/刷新”。右侧显示原脚本文本，“查看详细报告”显示本地报告。示例一、二有虚构日志，示例三用于验证未找到日志。
4. 继续保存其他 ID。列表第一行左侧显示项目、右侧显示名称，下一行显示 ID；可按项目、名称或 ID 搜索。清单不设置固定条数上限，本轮验证 20 条；超大量清单的性能尚未验证。
5. 新增遇到重复 ID 会提示，不覆盖旧记录。修改已有记录须点击该行“编辑”，编辑时 ID 固定；保存成功后表单恢复新增状态。
6. 上方选择“简体中文”或“English”。界面、错误提示、查询内容及报告使用所选语言。切换时清除旧显示并重新查询当前任务；有查询运行时暂不能切换。名称、项目、日志原文和路径属于源数据，不做翻译。
7. 点击“退出本机服务”后重新启动，任务和语言设置仍保留。关闭浏览器不会删除清单，也不会自动退出服务。

无需命令行或新依赖。运行使用 Windows 自带 PowerShell 5.1；Node 和 Playwright 仅用于开发测试。启动受设备策略阻止时，不要修改全局策略或提权，提供启动错误文字即可，不发送真实日志。

## 名称与项目

只有查询成功且原分析器找到无解析警告的有效索引名称时，才自动填充或更新名称。不同名称更新后显示 3 秒通知；正在编辑该任务时，名称框短暂标黄，不持续闪烁。原名称保留在本地，在右侧和编辑区可核对，不依赖短暂通知。仅保留最近一次替换前的名称，不是完整版本历史。

未找到日志、名称缺失或索引读取异常时，不覆盖已有名称。名称保存失败会提示，不能把查询成功当作保存成功。检测名称超过 80 字符时保留原清单名称，完整检测名称仍可查看报告。

原分析器没有可靠的归属项目字段，因此项目仅手填，不从名称或路径猜测。相同名称依靠项目和 ID 区分。

## 本地保存与隔离

每个实例的数据保存在本目录 `.local/`，默认实例为 `main`：

- `main/tasks.json`：任务和语言设置。写入采用临时文件及原子替换，避免半份内容覆盖完整清单；格式损坏时停止启动，不清空文件。
- 旧版 schema 1 清单会备份为 `tasks.schema1.<随机标识>.bak`，再迁移到 schema 2。名称和 ID 保留，项目为空。升级前退出旧服务，将旧包的 `windows-local/.local` 复制到新包相同位置，再启动新版；不要同时运行两份数据副本。回退旧版前退出新版，用迁移前备份恢复 `tasks.json`，新版本后续修改不会自动写回旧备份。
- `main/reports/`：本地报告和名称读取元数据。删除清单项不会删除报告。
- `main/fixtures/`、`main/runtime/`：自产虚构日志、原分析器的隔离副本。
- `main/connection.json`：本次本机服务的随机凭证，退出时移除。

持久保存不依赖浏览器缓存。已验证服务退出重启，未在本轮重启操作系统；删除解压目录也会删除其中数据。`.local` 属于本地专用内容，不提交或转发，其中可能有自定义名称、ID、路径和连接凭证。

允许保存任意标准 UUID，但查询仅接受全零前缀、末位为 1、2、3 的三个虚构 ID；其他 ID 明确拒绝，绝不回退读取真实目录。原脚本四处用户目录表达式替换为固定隔离目录，并反向逐字核对源代码；报告路径由服务固定。原分析器文件和统计算法保持不变，没有真实模式开关。

## 本机服务边界

- 仅监听 `127.0.0.1`，校验 Host、Origin 和随机访问令牌，不开放跨域。
- 客户端不能提供命令或文件路径。相同状态目录只有一个写者；清单的保存条数与查询并发数无关。
- 最多两个查询同时运行；同任务同语言的重复运行请求复用原查询。120 秒超时终止服务启动的子进程；退出服务同样终止未完成子进程。
- 新查询清除旧显示，输出绑定任务、运行标识和语言，报告仅对当前成功查询开放。不提供自动刷新、单次查询取消或系统自动启动。
- 输出只代表本次读取的快照，不等于 AI 实时运行状态。报告可能包含隔离目录的本机路径，不宜直接公开截图。

## 双语维护与验证

界面文本集中在 `desk.html` 的 `messages` 中，每个键同时提供中文和英文。修改功能或中文文本时，必须同步审阅英文、更新 `I18N-SOURCE-SHA256` 中文源标记，并回归两种语言。测试核对翻译对完整性和中文源指纹；指纹不能证明翻译语义正确，仍须人工对照。服务错误提示也须成对维护；查询与报告继续使用原分析器的语言目录，不另写一套统计翻译。

在已有 Node、Playwright 和 Edge 的环境中运行：

```sh
node .github/scripts/Test-WindowsSessionDesk.cjs
```

测试只创建隔离虚构实例，不安装依赖。覆盖 20 条保存、重复新增拦截、编辑与删除、旧格式迁移、重启、空名称和冲突名称、双语文本及报告、并发、失败清旧、输入和访问限制、窄屏以及退出。中英文输出均与直接执行同一隔离脚本逐字比对。原脚本必须不变，页面异常和外部 HTTP 请求均为零。

macOS、其他浏览器、真实数据、超大日志、海量清单、操作系统重启和安装签名尚未验证。本版本仍是 Windows 隔离验证版。
