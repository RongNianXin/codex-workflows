# Windows 会话查询工作台

[English](README.en.md)

版本：`0.2.0-dev.1`。本首版实现“保存名称和 ID → 点击任务查询 → 右侧显示原脚本输出”。**当前固定为隔离虚构验证模式，不读取真实会话。** 不是此前下载 A/B 文件的演示。

## 如何使用

1. 完整解压交付包，双击根目录的 `Start-SessionDesk.cmd`。从仓库运行时，双击本目录同名文件。服务在后台启动并自动打开默认浏览器；本轮只实测 Windows Edge。
2. 填写对话名称和任务 ID，点击“保存任务”。首次可展开“填入隔离验证 ID”，点“填入示例一”，再保存。示例一、二有虚构日志，示例三没有日志，用于验证失败提示。
3. 点击该行“查询/刷新”。右侧应显示“一、基本信息”“二、文件资源”“三、交接建议”等原脚本文本；“查看详细报告”显示本地 Markdown 内容。
4. 可以继续添加其他任务，按名称或 ID 搜索、修改名称或删除。相同 ID 保存为更新，不新增重复项；名称相同的任务依靠 ID 区分。
5. 点“退出本机服务”后再次双击启动，任务清单应恢复。关闭浏览器不退出服务，也不删除清单。

本轮不用选择日志文件、不需要命令行，也不用安装新依赖。Windows 自带 PowerShell 5.1 执行服务和脚本，不调用 Node；Node 和 Playwright 仅用于开发测试。受设备安全策略影响而启动失败时，不要修改全局执行策略或尝试提权：查看启动错误提示，提供错误文字即可，不发送真实日志。

## 保存与数据边界

每个实例的数据保存在本目录 `.local/` 下，默认实例为 `main`：

- `main/tasks.json`：名称与 ID 的持久清单，更新使用临时文件和原子替换；已有文件损坏时停止启动，不自动清空。
- `main/reports/`：原分析器生成的本地报告。删除任务记录不会自动删除报告；更新或移动软件前应保留原数据目录。
- `main/fixtures/`、`main/runtime/`：自产虚构日志及隔离分析器副本。
- `main/connection.json`：本次服务连接凭证；退出时移除，不作为任务清单。

清单写入磁盘，不依赖浏览器缓存；正常关闭或系统重启后设计上可保留。已验证服务退出重启后的恢复，没有在本轮重启操作系统。删除解压目录会同时删除其中的数据。清单与报告属于本地专用内容，不提交到仓库或上传。不要转发运行后的 `.local` 目录，其中可能包含自定义名称、ID、路径及连接凭证。

界面允许保存标准格式的任意 ID，但执行服务只允许三条固定虚构 ID：前缀为全零，末位分别是 `1`、`2`、`3`。其他 ID 查询会明确拒绝，绝不回退读取真实目录。示例一、二调用原脚本；示例三走相同隔离查找路径并返回未找到日志。

原脚本四处用户目录表达式被替换为当前隔离目录，反向替换逐字核对原源码；显式固定报告路径。没有修改原脚本算法或真实用户目录环境变量，没有真实模式开关。查询结果只代表本次脚本读取，不代表模型此刻正在生成。报告中的本地路径来自隔离目录，仍不宜直接公开截图。

## 本机服务限制

- 只监听 `127.0.0.1`，校验 Host、Origin 和随机访问令牌，不开放跨域访问。
- 只提供任务清单、固定分析器查询、当前成功查询的报告和退出接口；客户端不能传入命令或文件路径。
- 同一状态目录只有一个服务写者。最多两个查询同时运行，同任务运行期间重复请求复用原查询；120 秒未结束则终止本服务启动的子进程。
- 新查询清除该任务旧显示；查询结果绑定任务与运行标识，切换任务不会串结果。详细报告只对本次成功查询开放。
- 退出服务时终止尚在运行的分析器子进程。此版不支持自动启动、后台定时刷新或单查询取消。

## 验证与尚未覆盖项

现有 Windows PowerShell 5.1、无头 Edge 149 完成 20 项集成检查，包括本机免提权启动、单写者、访问限制、保存搜索与重命名、重复请求、并发归属、缺失日志失败、报告、重启恢复和退出。右侧文本与直接运行同一隔离分析器的终端输出逐字一致。原脚本文件未改变，页面无异常，无外部 HTTP 请求。

开发者可在仓库根目录、已有 Node/Playwright/Edge 的环境中运行：

```sh
node .github/scripts/Test-WindowsSessionDesk.cjs
```

预期 20 项通过，`errors` 为空、`external` 为 0。测试自行启动和关闭隔离实例，不安装任何依赖。失败时保留首个错误，不改原分析器或降低断言标准。截图只保存在 Git 忽略目录，不纳入公开文件。

macOS、默认浏览器的其他实现、真实会话、超大日志、操作系统重启、设备安全策略差异及安装签名尚未验证。本首版只验收交互和本地执行链，不是正式真实数据版本。
