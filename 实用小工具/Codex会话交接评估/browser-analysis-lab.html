格式、缓存与兼容边界
UTF-8 JSONL，每行一个对象。首行必须是以下标记；此标记只是格式门禁，不能证明任意外部文件已经脱敏，请仅选择自己生成的虚构样例。


{"type":"synthetic-session-lab","schema":1,"synthetic":true,"task_id":"DEMO-LAB"}
{"type":"turn_end","turn_id":"DEMO-TURN-1","input_tokens":100,"output_tokens":20}
{"type":"padding","text":"fictional payload"}


仅统计唯一 turn_end 的回合和输入/输出 Token 整数；不支持真实日志、模型判断、跨文件分段聚合或真实账单。重复回合、损坏 JSON、非法 UTF-8、未知类型及不完整末行均报错，不缓存部分结果。完整末行可没有换行。


后台按 256 KiB 分块读取。首次先验证内容指纹，再解析；复用缓存也要完整读取一次以核验内容。指纹是版本、分块大小、文件字节数及有序块 SHA-256 的组合摘要，不是普通文件 SHA-256。缓存只保留最近五个成功摘要在内存中，关闭或刷新页面即清除，不保存正文。


本验证页限制：单文件不超过 256 MiB、单行不超过 1,048,576 个字符、最多 100,000 个唯一回合；这些是本页保护范围，不是浏览器极限。内存占用还包括浏览器、解码缓冲、最长记录和回合去重表，不能宣称固定内存峰值。


只依赖文件选择、Blob、Web Worker、TextDecoder 和 Web Crypto，不依赖目录选择接口或浏览器扩展。缺少能力会明确停止；Windows Edge 实测情况见模块说明，macOS/Safari 仍需实机验证。
