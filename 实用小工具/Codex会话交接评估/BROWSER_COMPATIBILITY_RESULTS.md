# 浏览器与 PowerShell：虚构真实格式对照

验证日期：2026-09-05。输入来源为本目录 `check-codex-session.ps1` 的实现规则，不是实际用户会话。交付：[单文件浏览器验证页](browser-compatibility-check.html)、[20 组完整虚构输入与逐项对照结果](compatibility-fixtures.json)。

## 结论

20 组样例中，18 组的选定统计或拒绝条件一致，2 组存在已解释差异。此结论支持继续移植核心语义，但**不支持现在替换原分析器或宣称完整兼容**。

本轮没有修改原 PowerShell 文件，没有读取真实会话、安装系统依赖或执行远端操作。运行环境为现有 PowerShell 7 与 Windows Edge 149 无头；Windows PowerShell 5.1、macOS/Safari 均未实测。

## 隔离与证据方法

1. 自行生成 JSONL，保留 `session_meta`、`turn_context`、`event_msg`、`token_count`、累计 Token 和终止事件的字段结构。使用固定全零前缀虚构任务 ID、虚构回合标识与文本，并在元数据中添加 `synthetic_test: true`。该标记不是对任意外部输入的脱敏证明。
2. 原脚本默认读取本机用户目录，因此没有直接运行其默认入口。测试副本只替换四处 `$env:USERPROFILE` 路径表达式，将它们指向本轮生成的隔离目录；显式传入任务 ID 和隔离目录内的报告路径。反向替换后逐字符比对原源码，确保统计、分段、回合与报告算法均未改变；运行前后原文件哈希保持一致。未修改进程或系统的用户目录环境变量。
3. 在隔离脚本执行后取得内部结构化统计；浏览器独立实现结构化 JSON 解析，通过同一批文本输入计算。对无错误的核心样例，还用预先指定的回合数和 Token 总量约束浏览器输出，避免仅比较两个同样错误的结果。
4. 比较字段为分段数、排除候选数、上下文记录数、重复上下文数、基线/回退提醒、Token 推进次数、压缩次数、完成/中止/未结束回合数，以及每个回合的 ID、状态和输入/缓存输入/输出/推理/总 Token。错误结果按相同拒绝原因比较，不要求中英文错误文本相同。
5. 完整生成输入与实测对照值保存在 `compatibility-fixtures.json`。其中 JSONL 文本就是交给两个解析器的内容；输入中的额外虚构标记不改变原脚本算法。

## 两项差异与处置建议

### 1. 原分析器依赖 JSON 字段顺序，会静默漏计

`json-key-order` 样例把合法的 `event_msg` 对象改为先写 `payload`、后写外层 `type`。输入 Token 为 100；浏览器输出 100，原脚本输出 0，原脚本的解析警告数也是 0。

原因可追溯到原脚本 `Get-RecordShape`：它按文本中出现的前两个 `type` 推断外层与载荷类型，而不是按 JSON 对象层级读取。改变键顺序会让 Token 事件被跳过。这是有复现证据的正确性缺陷，不应为了保持兼容而在浏览器中复制。

建议另行修复原脚本的类型识别并回归正常顺序、重排顺序及大记录；本轮保持原脚本不变，以免改变对照基线。没有证据证明真实会话已经触发此缺陷，也不推断历史统计全部无效。

### 2. 截断记录：保留部分统计与直接拒绝的差异

`malformed-token-record` 样例包含一条截断 Token JSON。原脚本记录一次解析警告并继续输出已识别回合，Token 为 0；浏览器以 `malformed_json` 拒绝生成结果。

这不是“原脚本输出就必须模仿”的问题。只读分析活动日志时，末行尚未写完与中间历史记录损坏需要分别处理。当前浏览器严格拒绝可以防止把部分统计标为完整，但尚未达到活动会话可用性要求。

建议定义统一的数据完整性状态：完整、末尾仍在写入、历史记录损坏。允许保留已确认统计时，应标明缺口及重新读取条件；损坏记录不得无声记为零 Token。该策略仍待后续设计与虚构样例验证，本轮没有自行放宽。

## 未覆盖与停止边界

- 这不是完整功能移植：未比较文件类别占用、Base64 扣除、历史字节里程碑、前三回合正文、报告排版或综合交接评分。
- 浏览器验证页仅接受小型 UTF-8 虚构样例。数值只接受 JavaScript 安全整数；不覆盖 PowerShell Int64 的全部范围、字符串数值转换或其他编码。回合 ID 大小写差异、相同文件名的跨目录分段、缺失时间戳和更多历史格式仍需专门用例。
- 原脚本读取记录前 4,096 字符的启发式逻辑存在更多潜在边界，本轮只对字段顺序给出了复现证据，不虚构其他已发生缺陷。
- 上一阶段的 64 MiB 后台解析测试使用另一套简化格式，不能挪用为本兼容解析器的大文件性能证明。尚未把本页算法并入后台分块实现与内容缓存。
- 文件内容标记、成功样例或两者一致都不能替代真实数据授权；Mac/Safari 仍需单独实机验证。
