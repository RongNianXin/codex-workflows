# 浏览器截断状态实验

[打开单文件实验页](truncation-browser-lab.html)。无需安装依赖或启动服务，直接用浏览器打开 HTML；当前仅实测 Windows Edge，macOS/Safari 待验证。

## 操作与预期

1. 点击“下载末尾截断”和“下载已补全”，获得本页生成的两个虚构 JSONL 文件。
2. 在首次快照区点击“选择虚构文件”，选择末尾截断文件。预期显示“末尾不完整，原因待确认”。
3. 点击“再次选择文件”，选择已补全文件。预期说明前次快照末尾已补全、旧缓存失效；不宣称写入进程活跃或正式评估成功。
4. 可重复选择同一文件核对内容不变，或选择“中间损坏”“内容改写”样例观察异常。每次第二次选择都与左侧首次快照比较；要更换基准，重新进行首次选择。
5. 点击“查看判定依据”查看行号、内容指纹和状态。点击“清空快照”或刷新页面会清除内存状态。

若预期不符，请提供页面状态文字和浏览器版本；无需发送任何真实会话文件。页面仅接受固定实验任务与分段标记，每个文件最多 1 MiB；该标记不能证明输入已经脱敏，请仅选择页面生成的虚构样例。

## 实测证据

使用现有 Playwright 库和无头 Windows Edge 149，从本地文件 URL 打开页面。24 项交互断言全部通过：

- 四种样例实际下载，再经页面按钮触发文件选择事件，传入下载得到的虚构文件；首次选择前第二次选择不可用。
- 首次截断、同文件重复选择、末尾补全、中间损坏及物理行号、内容改写及缓存失效显示正确。
- 无标记和超过 1 MiB 的输入被拒绝，旧快照保留；空选择不清除已有结果。空选择测试模拟取消后的无文件状态，没有人工操作原生文件对话框。
- 注入虚构读取失败后显示错误；受控延迟读取期间展示加载状态、禁用两次选择按钮。读取中清空后，即使旧读取结束也不覆盖清空结果。
- 清空与刷新移除内存快照；390 像素宽度无横向溢出；测试期间 HTTP 请求数为 0，页面异常数为 0。桌面截图已人工查看。

读取失败和延迟通过测试环境临时替换文件读取方法模拟，未改系统文件权限或制造真实磁盘故障。页面未依赖测试注入。

## 数据流与边界

用户主动选择 → 大小检查 → 实验头检查 → UTF-8 字节记录检查 → SHA-256 内容指纹 → 与首次快照对照 → 展示状态。文件名只作显示，不作任务身份或内容判断。显示使用纯文本，不执行文件中的 HTML 或脚本。

实验缓存只指当前页面保留的快照；每次选择仍重新读取、核对内容与状态，没有持久缓存或后台监控。内容不变不会提升结果完整性；改写或缩短不会沿用旧累计值。本页不计算 Token，不调用正式分析器。实验头占第一行，错误行号按实际文件位置显示。

这次验证不包括正式统计一致性、真实会话、macOS/Safari、大文件性能或所有历史格式。最多 1 MiB 是本实验的输入限制，不是已完成性能验证的结论。PowerShell 分析器和此前浏览器分析页保持不变；没有安装依赖或远端写入。

下一步可在继续使用虚构数据的前提下，验证完整性状态与现有浏览器兼容解析器衔接：不完整输入阻止完整结论，完整输入交给原解析器，并回归已有回合、Token 基线及多分段样例。该衔接尚未实施。
