# Codex 会话交接评估

[English](README.en.md)

保存常用任务 ID，一键查看本机 Codex 会话的回合、文件大小、上下文压缩及交接参考信息。**当前推荐下载版本：Windows 工作台 0.2.0-dev.9；仓库内待发布源码为 0.2.0-dev.10。** 无需输入命令；源会话只读，数据不上传。

## 下载与启动

1. [下载 Windows 独立工具 ZIP](https://github.com/RongNianXin/ChatGPT-Workflows/releases/download/windows-sessiondesk-v0.2.0-dev.9/Windows-SessionDesk-0.2.0-dev.9.zip)，完整解压，双击根目录 `Start-SessionDesk.cmd`。无需克隆整个仓库；不要单独打开 HTML。
2. 已克隆仓库的用户，双击 [Start-SessionDesk.cmd](Start-SessionDesk.cmd)。仓库源码可能先于下载包，实际版本以页面顶部显示为准。
3. 保存任务 ID，单项“查询/刷新”只更新该任务；“一键刷新”更新完整列表。名称与本地项目自动读取。右侧基本报告与详细报告分区显示，可切换简体中文或 English。

使用 Windows 自带 PowerShell 5.1 和浏览器；当前验证 Windows Edge，macOS 与其他浏览器未验证。本版本仍为开发预览，不宣称已经完成所有设备兼容性或超大日志验证。

`windows-local` 是正式程序内部目录，不是临时文件；日常只需运行本目录的启动 CMD。个人任务与历史保存在其 `.local` 中，不随仓库分发。

## 日常操作

- 常用任务没有固定条数上限，已回归 20 条；支持搜索、上下移动和“一键排序”，顺序保存在磁盘。“一键刷新”最多同时查询两个任务，完成后保留原选中项；原先没有选中项时右侧继续为空。
- 最新成功结果达到原分析器的“建议交接”阈值时，任务行显示浅黄色背景、橙色边条和文字标签。该标记来自查询快照，不代表实时状态；旧快照缺少等级字段时保持普通样式。
- 每个任务、每种语言保留最近一次成功查询的基本输出和详细报告。重开显示原查询时间及“历史快照”提示，只有主动查询才更新统计。
- **仅关闭网页不会关闭后台服务。** 不再使用时点击页面顶部的“退出工具”，停止本工具服务及未完成查询，不影响 Codex 对话任务。按钮提供中英文悬停说明；退出后可以关闭页面，下次双击启动入口恢复清单与已保存结果。
- 中断或失败的刷新不会把旧历史改成新成功；此前保存的历史仍可在重开时查看。查看结果不代表 AI 当前仍在运行。

## 评分与滑条

任务卡片的交接参考分为 0～10 分：文件体积按 30、50、100、200、400 MiB 计 0～5 分，自动压缩次数按 4、7、10、15、20 次计 0～5 分。0～2 分暂不建议交接，3～7 分显示“建议交接”，8～10 分（含 8）显示“必须交接”。这些是本地经验规则，不是 OpenAI 官方限制。

每个有评分的任务卡片显示一条 10 格静态滑条，在 3 分和 8 分处各有细刻度；鼠标悬停或键盘聚焦会显示当前分数和等级。最近输入占窗口比例不计入总分，也不在任务卡片上生成交接提醒；终端和报告仍保留该指标供诊断。旧快照没有评分字段时显示“无评分数据”，不会伪装成 0 分。

详细操作、存储位置、历史失效条件和双语维护要求见 [Windows 工作台说明](windows-local/README.md)。[真实界面预览](../../SHOWCASE.md)集中展示脱敏截图。

## 升级与旧版本

升级前退出旧工具，备份其 `windows-local/.local`，再复制到新目录对应位置；不要覆盖另一份已有数据。目录内含任务清单、历史与报告，删除程序目录前必须保留该目录。dev.5 及更早版本不能复原从未保存的基本输出；完整历史保存从 dev.6 成功查询开始。

旧 HTML 原型和虚构演示已退出正式交付入口，其阶段代码可从 Git 历史检索。本页只推荐当前 Windows 版本；命令行分析器继续保留，供脚本调用与独立核对，不是另一套统计算法。

## 统计与隐私边界

本工具给出工程参考，不承诺官方阈值或实时状态。多分段 Token 基线、截断输入、持续写入的日志和缺失计数可能影响完整性；结果是读取快照，不是冻结的实时总账。名称和项目依赖 Codex 当前本地记录格式，格式变化时可能需要适配。

详细报告和历史可能包含完整用户输入及本地路径，只保存在 `.local`，不得未经审阅直接公开。ZIP 不包含这些私有文件。仅监听本机回环地址并校验随机连接凭证；退出不会关闭其他程序或 Codex 任务。所有版本都应保留原分析器的完整性提醒，不能把缺失 Token 当作零。
