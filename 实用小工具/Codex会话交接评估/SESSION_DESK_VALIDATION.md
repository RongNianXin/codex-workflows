# 单页虚构数据验证版

[打开会话工作台](session-desk-validation.html)。仅这一份 HTML 即可在浏览器中打开，不需要服务器或依赖安装。当前实测 Windows Edge，macOS/Safari 待验证。

## 最小操作

1. 选择左侧虚构任务。搜索支持名称、项目及 ID；同名任务通过项目和 ID 区分，星标可收藏。
2. 展开“准备当前任务的虚构样例”，下载完整 A、B；点击“选择分段并分析”，同时选入这两个文件。
3. 预期摘要显示 1 个回合、130 Token、2 个分段；详细统计显示 1 次基线提醒，即后段首个累计快照只作为比较起点，避免重复计入历史。
4. 再选截断样例，预期阻止统计并移除旧摘要；重新选择完整集合即可恢复。若不符，请提供状态文字和浏览器版本，无需真实会话文件。

## 统一状态与范围

页面采用一套明确状态：尚未选择、正在读取与检查、所选集合已分析、输入未通过检查、读取或分析失败、已取消本次读取。每个任务独立保存当前内存状态，加载或失败后不显示旧统计；切换任务会取消旧任务尚未结束的读取，迟到结果不发布。再次选择替换整个集合，不追加旧累计值。

搜索、收藏、选择文件、完整性检查、兼容解析、摘要和详情现在同处一页。收藏与结果只在页面内存中保留，刷新清除；不保存持久结果，不自动发现目录，不设置虚构的过期倒计时。分析时间仅表示本次快照的处理时间，不代表磁盘内容仍最新。

统计核心与原兼容页逐字一致；整合页在外部检查所选分段均属于当前任务。不匹配的分段使整组拒绝，避免静默排除后把部分集合显示为完整。原 corpus 的 `wrong-internal-id` 因此在整合层预期为拒绝，其余统计或拒绝原因维持原结果；没有修改 PowerShell、原兼容页、原衔接页或旧原型。

详情只包含选中集合的回合、Token、分段和缺口依据，不提供原 PowerShell 完整报告、正文摘要或专业交接结论。文件标记不证明脱敏，仍只允许使用虚构样例；页面不能证明全部历史分段已选齐。

## 验证

现有无头 Windows Edge 149 中，19 组检查通过，其中一组逐项回归现有 20 个兼容样例。覆盖搜索收藏、摘要详情、重复/替换选择、截断阻断、同名任务与文件身份隔离、切换取消、读取失败恢复、输入限制、样例下载、窄屏和刷新清除。统计核心源码一致性核对通过，HTTP 请求与页面异常均为 0。

单段超 2 MiB、集合超 16 MiB、超过 32 段均被拒绝；另将 8 个各 2 MiB 的有效虚构分段直接交给整合页分析函数，恰好 16 MiB 输入成功。两次自动化调用往返分别约 111 ms、140 ms，包含测试通信，不是纯解析耗时或性能保证。该边界样例不是文件选择端到端性能测试，也未测量峰值内存。解析仍在主线程执行，输入复杂时可能短暂停顿；本版不移植大文件 Worker，不移用此前简化格式的 64 MiB 性能结论。

在已有 Playwright 库和 Edge 的环境中复现：

```sh
node .github/scripts/Test-SessionDeskValidation.cjs
```

预期输出 `count: 19`、空 `errors` 和 `requests: 0`，退出码为 0。全部输入取自页面虚构生成器或仓库虚构 corpus；结果和截图写入被 Git 忽略的本地测试目录。脚本不安装浏览器或依赖；环境缺失时保留首个错误即可，不必为本轮安装。

## 已知限制

- 不包含批量自动刷新、持久结果缓存、自动目录发现或真实数据接入。各任务需主动选择自己的文件集合。
- macOS/Safari、更多历史格式、真实 I/O 故障和完整正式报告尚未验证。
- 输入上限是本实验的保护范围，不是所有机器的安全性能保证；连续大负载、峰值内存和主线程响应需在扩大使用范围前验证。

本轮只交付单页虚构验证版及测试说明，没有读取真实会话、安装依赖或远端写入。
