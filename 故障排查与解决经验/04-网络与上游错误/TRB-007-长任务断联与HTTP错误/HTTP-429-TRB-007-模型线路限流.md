# TRB-007 · HTTP 429：模型线路限流

| 字段 | 内容 |
| --- | --- |
| 错误码 | `429` |
| 典型正文 | `rate_limit_error` / `All available accounts are currently rate-limited` |
| 根因范围 | 当前模型线路的可用账号池被限流；不等于用户全局额度耗尽 |
| 当前状态 | 可切换健康模型恢复；原线路恢复时间待服务方确认 |

## 识别与排除

同时核对错误正文、实际模型线路、同一时段其他模型的成功/失败对照、任务状态和是否产生副作用。若请求未进入正常生成且没有消息项或用量，不能据此认定用户账号全局额度耗尽。官方 429 还可能表示速率、余额或组织/项目限额，必须结合正文判断。

## 最小恢复

1. 保存脱敏错误正文和线路信息，停止对同一模型线路的连续重试。
2. 在授权范围内切换到同一时段已验证健康的模型，先做无副作用连通性检查。
3. 检查 HTTP 200、可读回复和任务状态恢复后，再继续业务。
4. 服务方确认账号池解除限流前，不切回故障模型；必须切回时先做新的只读探针。

此前同线路先出现 `502`、随后 `429` 时，应把 `502` 作为线路不稳定信号记录，但不能把两者合并为同一根因。该故障与工具调用配对 `400` 分开处理。
