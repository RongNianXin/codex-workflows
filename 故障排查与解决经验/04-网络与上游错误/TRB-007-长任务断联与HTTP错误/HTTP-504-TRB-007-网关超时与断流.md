# TRB-007 · HTTP 504：网关超时与断流

| 字段 | 内容 |
| --- | --- |
| 错误码 | `504` 或等价的流式断开 |
| 根因范围 | 网关等待上游响应或后续流式数据超时；具体层级待确认 |
| 当前状态 | 状态不明时优先恢复现场 |

## 排查

记录失败发生在首字节、工具调用前后还是输出过程中，核对任务状态、已写文件和外部副作用。客户端重连次数不等于人工重试次数；一次长任务可能包含多轮请求。

## 最小恢复

1. 状态不明时停止直接重放，保存现场和最后可确认断点。
2. 仅在操作确认幂等、无副作用且授权明确时退避重试一次。
3. 仍失败时在干净任务中做只读探针，或按授权切换健康线路。
4. 从状态索引或交接快照恢复，不把“你好”成功当作业务恢复验收。

若同时出现结构化 `400`、`429` 或其他明确错误正文，转对应文件；不要只按“超时”解释全部失败。
