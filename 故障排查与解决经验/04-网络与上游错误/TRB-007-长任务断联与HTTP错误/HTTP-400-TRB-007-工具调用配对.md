# TRB-007 · HTTP 400：工具调用结果配对失败

| 字段 | 内容 |
| --- | --- |
| 错误码 | `400` |
| 典型正文 | `No tool call found for function call output` |
| 根因范围 | 工具结果与调用关联字段在客户端、代理或上游转换中不匹配；责任层待确认 |
| 当前状态 | 未修复；已有取证和停止条件 |

## 识别与排查

保存失败事件、事件类型、关联字段、转换前后响应和已有副作用。内部日志缺少某个字段，不能直接证明最终 HTTP 载荷非法，也不能据此指定客户端或代理为唯一根因。区分工具结果配对错误与对话过长 `400`。

暂停向同一失败业务会话重复投递，不自行补造 `call_id`、过滤整个 heartbeat、删除日志或重放业务。若要主动复现，必须使用无业务副作用的隔离任务并另行取得授权。

## 处置与验证

1. 保留原会话和失败批次，核对是否已有文件、外部请求或其他副作用。
2. 读取当前规则和交接材料，记录失败发生在工具调用前、工具结果返回后还是普通消息阶段。
3. 在授权范围内使用新任务验证基础文本、正常工具调用和后续普通消息。
4. 只有转换前后关联字段、实际响应和副作用均可核对时，才评估兼容修复。

新任务成功只证明恢复样本可用，不证明旧会话修复或所有线路兼容。
