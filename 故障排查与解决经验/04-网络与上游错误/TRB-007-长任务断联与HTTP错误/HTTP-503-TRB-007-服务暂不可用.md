# TRB-007 · HTTP 503：服务暂不可用

| 字段 | 内容 |
| --- | --- |
| 错误码 | `503` |
| 根因范围 | 服务维护、容量不足、熔断或链路无健康上游；具体原因待服务方确认 |
| 当前状态 | 先保留现场，再评估有限恢复 |

## 排查与恢复

先确认失败前是否已经写入文件、调用外部系统或产生其他副作用。仅在操作明确幂等且无副作用时，授权退避后最多重试一次；状态不明时不要直接重放。核对同一时段服务健康、线路对照和服务方公告/日志。

若仍返回 `503`，停止业务投递并等待服务方恢复或按授权评估备用线路。切换后先做无副作用探针，验证 HTTP 200、可读回复和任务状态，再继续业务。

`503` 前已经写入的结果必须保留并纳入交接材料；不能因错误响应覆盖或删除它们。
