# TRB-007 · HTTP 502：上游网关或代理转发错误

| 字段 | 内容 |
| --- | --- |
| 错误码 | `502` |
| 根因范围 | 上游暂时不可用、代理无法取得有效响应、连接失败或协议转换错误 |
| 当前状态 | 需按错误正文和证据层分流，暂无唯一根因 |

## 排查

记录 `cause`、`upstream_status`、实际出站线路、模型、失败阶段和是否已有副作用。只有正文明确含上游 `5xx` 且无字段/分页谱系错误时，才可暂按瞬时上游故障处理；缺少 `upstream_status` 时不得补写。

对照同一时段的干净任务和其他模型。长任务成功或失败都不能单独证明模型复杂度是根因；代理标签也不是服务端证据。

## 最小恢复

1. 先核对已写文件、外部请求和任务状态，保留现场。
2. 无副作用且正文明确为瞬时上游错误时，按授权有限退避重试一次。
3. 需要换线路时，先在干净任务做只读探针；成功后从状态索引或交接快照恢复。
4. 结构化参数、`encrypted_content` 或分页谱系错误不得重试，转对应故障文档。

一次成功不证明线路永久修复；连续失败时等待服务方日志和恢复确认。
