# TRB-007 · HTTP 404：模型不支持或映射错误

| 字段 | 内容 |
| --- | --- |
| 错误码 | `404` |
| 典型正文 | `model is not supported by any configured account in this group` |
| 根因范围 | 当前账号组没有支持该模型的账号，或模型映射错误 |
| 当前状态 | 有明确分流和恢复方法 |

## 排查

核对当前账号组、实际模型名、模型映射、套餐支持范围和出站线路。错误正文若明确指出模型不支持，改变推理强度不能解决；不要把它解释成上下文过长或网络超时。

## 最小恢复

1. 停止对不支持模型的连续重试。
2. 在授权范围内改用账号组已确认支持的模型，或修正模型映射。
3. 用无副作用请求验证 HTTP 200、可读回复和任务状态。
4. 验证通过后再继续原业务；记录实际模型和线路，避免下次误切回。

如果正文没有模型不支持签名，转总索引按其他 `404` 证据分流。
