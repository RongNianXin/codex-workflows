# TRB-007 · HTTP 401：凭据或授权被拒绝

| 字段 | 内容 |
| --- | --- |
| 错误码 | `401` |
| 根因范围 | 凭据过期、登录失效、账号或授权被上游拒绝 |
| 当前状态 | 按凭据和线路排查 |

## 排查

保存完整错误正文并脱敏。核对当前实际使用的线路、账号组、模型映射、登录状态和凭据有效期；不要把代理标签当作账号已经切换成功的证明。禁止在同一凭据上连续重试。

## 最小恢复

1. 停止同一凭据的业务投递并保留现场。
2. 在授权范围内重新认证或切换到已确认有效的账号/线路。
3. 先发送无副作用探针，确认 HTTP 200、可读回复和任务状态恢复。
4. 探针失败时停止，等待服务方或凭据管理员确认；不删除历史、不迁移会话。

`401` 与 `429` 的限流原因、`404` 的模型不支持原因不同，不能混用处置。
