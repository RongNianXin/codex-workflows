# Codex 历史任务批量迁移包

**简体中文** | [English](README.en.md)

## 当前状态

- **真实安装已暂停。** `--apply` 会在扫描、备份或修改真实任务之前失败关闭。
- 原因是旧版只验证单个文件，没有证明改写父会话后，子分段的 `history_base.end_byte_offset` 仍指向相同字节前缀。
- 公开包暂时只保留转换源码、纯虚构测试和已有备份的回滚能力，供审查与后续修复使用。
- 本机生成的扫描报告可能包含绝对路径和真实任务 ID，已由 `.gitignore` 排除，也不是安装器的运行依赖。
- `--self-test` 和谱系测试只使用合成值或临时目录，不枚举真实会话内容。

## 迁移目的

仅扫描 Codex 当前未归档的任务，移除其中与原提供商绑定、切换账号或 API 提供商后无法验证的隐藏推理和压缩密文，同时保留用户消息、AI 可见答复、工具调用及其他非加密结构。`archived_sessions` 中的已归档任务不会被扫描、备份或修改。它解决的是“继续同一个可见任务”的兼容问题，不会也不能把原提供商的隐藏推理密文转换给另一个提供商。

## 公开验证结论

本地测试确认：失败保护生效、加密字段按预期移除、非加密结构摘要保持一致，手工备份不会被识别为正式任务。测试结论不能代替对当前 Codex 版本和个人备份的复核。

## 安装状态

不要双击 `安装批量迁移.cmd` 处理真实任务。当前入口只会说明风险并退出。

以下旧命令也已暂停，不能通过精确任务 ID 绕过：

```powershell
node install_bulk_codex_migration.mjs --apply --task "00000000-0000-0000-0000-000000000000"
```

恢复真实安装至少需要证明：引用目标存在；偏移是非负安全整数且不越界；父文件候选在每个引用偏移之前与原文件逐字节相同；归档或集合外父任务也被显式纳入验证。当前没有完成真实数据验证，因此仍保持失败关闭。

可以运行：

```powershell
node safety_tests.mjs
node lineage_tests.mjs
node install_bulk_codex_migration.mjs --self-test
```

第一项验证可见内容保真和未知密文失败关闭；第二项仅在临时目录生成完全虚构的无分页、父子、多级、多子任务、集合外引用、越界、重复运行和恢复原件样例；第三项只检查合成的进程名称、任务选择器和临时文件元数据，不读取真实会话。

## 回滚

Codex 与 CC-Switch 完全退出后，双击 `回滚最近一次批量迁移.cmd`。回滚前，工具还会先备份迁移后的现场，避免覆盖后无法取证。

## 备份位置

`<USER_HOME>\Documents\Codex\CodexSessionBackups\bulk-<TIMESTAMP>`

每次安装目录内包含 `manifest.json`、原始任务文件副本，以及当时存在的 Codex/CC-Switch 配置和数据库副本。恢复时应使用回滚脚本，不应只覆盖 `config.toml`；单独还原配置不会还原任务历史，也可能制造配置与历史状态不一致。

## 已知边界

旧版批量迁移只处理运行时已经存在于未归档任务中的密文，并忽略跨文件分页谱系。即使以后补齐谱系验证，某个提供商继续写入新的隐藏密文后，再切换到不能解密它的提供商，仍可能复发。长期兼容仍需要上游正式支持跨提供商状态转换；仅靠 `model_provider = "custom"` 不能改变密文归属。

本工具不是 `codex-session-cleaner` 或 `codex-rescue` 的派生打包，也没有复制它们的源码。相关启发、许可证和实现差异见[说明文档](<../../相关项目、许可证与差异说明.md>)。
