# 工作流概览

本页只提供导航，不单独维护另一套规则摘要。本分类目录中的 `00`～`10` 是第二代工作流的唯一正式规则来源；如本页与编号文档不一致，以编号文档为准。

## 从哪里开始

1. 使用者只需打开 [01-操作者操作手册.md](../01-操作者操作手册.md)，按“下载后 3 步启动”登记本地规则目录并选择场景。
2. AI 从 [00-第二代工作流总览.md](../00-第二代工作流总览.md) 读取当前版本、完整编号注册表和按需加载顺序。
3. 正常交接候选按 [总指挥轻量交接启动配置.md](../总指挥轻量交接启动配置.md) 核验；指纹异常时才展开对应正式规则。

专项任务不是默认执行层。只有独立并行、独立审查、高成本证据隔离或能力缺口对整个工作流有明确净收益时才读取 `03` 并创建最少量任务；使用者不需要向两个窗口重复描述或转发结果。

完整编号导航只在 `00` 维护，避免两份注册表漂移。公开信息、Secret、路径和来源项目隔离要求见 [SECURITY_BOUNDARY.md](SECURITY_BOUNDARY.md)；规则变更的通用事件格式见 [RULE_CHANGE_EVENT.md](../templates/RULE_CHANGE_EVENT.md)。

## 辅助工具

- [自动化测试经验与可信结果门禁](AUTOMATED_TESTING_LESSONS.md)：浏览器、真实媒体、模型、跨版本对照或人工结果冲突时按需完整读取；它不产生测试、产品修改或远端写入授权。
- [Codex 会话交接评估](../../../实用小工具/Codex会话交接评估/README.md)：只读检查本地会话文件容量、自动压缩次数和最近输入占窗口比例，辅助判断是否准备交接。
- 工具阈值属于本地经验规则，不替代任务阶段、交接断点和实际理解质量判断。
