# 模型与独立审查成本：脱敏案例

本案例只保留聚合统计和通用活动分类。原始任务、领域、人员、地点、组织、账号、路径、时间线、标识及逐条消息均未纳入。它用于说明研究方法，不能证明某个模型或交接时点普遍最优。

## 可复核结论

一次长任务的私有记录包含 50 个用户回合、555 条已落盘用量记录。每条记录通过模型和 Token 向量与本地费用记录一对一匹配，时间偏差均小于两秒；合计估算费用约 59.30 美元。费用来自本地估算字段，不等同供应商结算账单。

成本集中在较长的执行链：最贵三轮占约 37.8%，22 个单请求回合合计约占 2.5%。高成本轮次通常包含多项恢复、环境核对、界面调整或交接准备，也包含必要验证，不能仅凭工具调用数量判定浪费。

旧端交接准备约占总费用 10.7%。案例没有完整的新端接收成本，也没有“提前交接后执行同类任务”的对照组，因此不能据此制定固定交接阈值。更可靠的判断是在稳定业务边界比较预计后续收益与旧端准备、新端读取、缓存变化和重复验证的总成本。

## 独立审查观察

该研究的主执行与收口共 41 次模型请求，独立审查者 28 次，合计估算费用约 14.65 美元；独立审查者的直接费用约占 27.5%。双方均使用同一高能力模型的低推理档位，完整工作流没有单 Agent 对照组，因此不能把全部成本归因于独立审查。

独立审查发现并纠正了一项会改变模型分组结论的事实错误，说明审查具有实际价值。同时，完整历史复制、重复机械核算和频繁通信都会增加成本。改进方向是精简证据包、确定性工具优先、首轮无问题即结束、修订后定点复核，而不是取消高风险审查或持续讨论到意见一致。

## 使用边界

- Token 与费用分别核算，不相加；便宜模型只有达到同等验收才构成节省。
- 缓存输入仍有绝对成本；高缓存比例不等于低费用或上下文没有负担。
- 模型与推理档位建议属于待验证起点，不根据单案例排名。
- 后续只在本来就会发生的可比任务中记录双方总用量、费用、漏检、返工和人工介入，不为实验重复生产工作。
- 公开版本只引用本页；原始账本、消息、指纹和本地研究文件不得随本页发布。
