# Codex 任务路径故障修复工具

## 目标

提供可双击的本地 EXE，只诊断和修复已知路径故障，绝不自动归档任务。

## 阶段

- [x] 核对官方任务标题查询接口
- [x] 明确上游根治与本地兼容方案的边界
- [x] 移除脚本和 GUI 中全部归档能力
- [x] 增加“扫描并修复全部异常”功能
- [x] 增加按任务 ID 或完整标题分析、确认后修复功能
- [x] 完成安全回归、隐私检查和重新交付
- [x] 对抗式审查“在线扫描、离线修复”的并发与交互边界
- [x] 将批量在线扫描改为同一只读快照并返回明确结果码
- [x] 将 GUI 改为发现异常后才提示退出 Codex
- [x] 重新编译并完成并发、安全、文档和 Git 验证

## 验收标准

- GUI 支持一键扫描并修复全部异常，不要求任务 ID。
- GUI 支持输入任务 ID 或完整标题分析指定任务。
- 指定任务仅在唯一匹配、命中已知异常并经确认后修复。
- 正式修复前要求 Codex 完全退出并创建一致性备份。
- 只读扫描允许 Codex 保持运行；发现异常后才提示退出。
- 用户确认修复后必须重新扫描，不能复用可能已经过期的在线扫描结果。
- 源码、脚本和 EXE 不包含任何归档调用。
- 不删除任务、不修改签名程序、不联网写入、不 Push。

## 已知风险

- 本地工具是兼容层，不是 OpenAI 上游补丁。
- 私有状态库结构或 CLI 位置随版本变化时，工具应失败关闭，不能猜测修改。
- 真实数据库修复不在开发验证中执行，需由用户退出 Codex 后自行运行。
