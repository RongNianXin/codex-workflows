# Findings

- 用户明确禁止自动归档；工具只能诊断和规范化异常 `rollout_path`。
- 批量扫描直接读取本地状态库中 `archived=0` 的记录，不需要逐个任务 ID，也不调用任务归档接口。
- 官方 `thread/list` 支持 `searchTerm` 标题片段搜索，并返回用户标题 `thread.name`；指定标题模式必须额外做完整相等匹配。
- 完整标题匹配超过一个时拒绝修改并列出 ID，避免同名任务误修。
- 正式修复必须要求 Codex 完全退出，先做 SQLite 一致性备份，再用事务和旧值条件更新。
- 安全命中条件是本地扩展盘符路径、普通/扩展路径都存在、无规范化冲突、数据库完整性正常。
- 已归档记录、普通路径、UNC 扩展路径、缺失文件和冲突记录都不能修改。
- 数据库触发器、后台常驻轮询和修改签名程序会扩大兼容性与并发风险，不作为本地方案。
